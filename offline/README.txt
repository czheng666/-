临床采集 · 单机离线版

使用方法：
1. 保持 offline 文件夹和 docs 文件夹在同一层级。
2. 双击 start-clinical-capture.cmd。
3. 浏览器会自动打开临床采集页面。
4. 关闭启动窗口即可停止服务。

重要说明：
- 必须完整保留 docs 文件夹，里面包含网页、PaddleOCR 模型和浏览器运行文件。
- 不需要安装 IIS、Node.js 或 Python。
- 识别主引擎使用内置 PP-OCRv6 small；首次识别会占用一定内存和时间。
- 照片、OCR结果和归档保存在当前电脑的浏览器中，不会写入医院服务器。
- 更换电脑前，请在网页底部导出 JSON 备份；Excel适合科研分析，JSON适合恢复档案。
- 这只是单机本地服务，不会让其他电脑自动看到本机档案。
- 如果 Windows 弹出脚本或防火墙提示，请按医院规定处理，不要擅自放开外网访问。
