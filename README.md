# 临床采集 · OCR 归档原型

这是一个纯客户端、移动端优先的临床资料拍照归档原型：

- 使用设备摄像头拍照，或从相册导入图片
- 默认使用本地 PaddleOCR.js PP-OCRv6 small；保留 Tesseract.js 作为可选备用引擎
- 自动提取识别结果里的常见数字/单位，支持人工校对
- 首版资料类型：血常规、肝肾功能、止凝血、CT、彩超
- 支持门诊病历、住院病历、出院小结、处方/用药、病理报告、心电图等常见文本资料
- 以个人/患者姓名或病案/就诊号为主键归档，同一个人的多份资料会自动分组显示
- OCR 后自动识别个人姓名、住院号、门诊号、病案号和病历号；识别不到时可人工填写
- 根据 OCR 关键词自动判断资料类型；检验单归纳常见项目/结果/单位/参考范围，CT/彩超归纳检查部位/所见/印象或结论
- 检验单按 OCR 表格行动态读取全部指标，不再限制为预设项目；同时保留项目、英文缩写、结果、参考范围、单位、异常提示和识别置信度
- OCR 结果表支持人工直接修改项目名称、英文缩写、结果、参考范围、单位和异常提示；嗜酸性粒细胞会按上下文规范为 `EO%`（百分比）或 `EO#`（绝对数）
- 针对当前医院报告格式内置缩写校正词典，覆盖血常规的 WBC、NEUT%/NEUT#、LYMPH%/LYMPH#、EO%/EO#、BASO%/BASO#、RBC、HGB、HCT、MCV、MCH、MCHC、RDW-CV、RDW-SD、PLT、PCT、PDW、MPV、P-LCR，以及肝肾功能和止凝血常见缩写；未知项目仍保留 OCR 原文
- 增加阑尾炎病例现场采集面板：按资料类型展开症状、首次化验、CT/彩超、治疗时间、术中发现、病理和结局字段；OCR可先填入可识别内容，人工字段支持边采集边填写，并自动保存未完成草稿
- 阑尾炎现场字段按同一患者的多份资料合并到“病例主表”，保留有/无/未描述/不确定等状态，不把未提及误判为无；归档后可选择继续当前病例并补拍下一份资料
- 资料与图片保存在当前浏览器的 IndexedDB；不对接医院系统、不上传服务器
- 支持标题、资料类型、备注、搜索、筛选、详情查看、删除和 JSON 导出
- 支持导出临床数据收集科研数据包 `.xlsx`：包含“病例主表”“资料记录表”“指标明细表”“变量字典”四张表
- 归档前必须勾选人工复核；病例卡片、资料详情和导出表会保留“人工已复核/待人工复核”状态
- 支持导出 JSON 原始备份，也支持在另一台设备导入备份并按记录 ID 合并恢复
- 档案区显示当前记录数和浏览器存储占用，便于在连续采集时及时备份
- “病例主表”按个人/患者归档；“资料记录表”一份检查资料一行；“指标明细表”一项识别指标一行，不预设血常规或肝功能项目清单，所有实际识别到的指标都进入长表
- 每项指标同时保留结果原值、可分析数值、单位、参考范围、异常提示、OCR 置信度、复核状态和来源资料，适合后续在 Excel/WPS 中筛选、清洗和统计
- OCR 前会保留原图，并生成整图、姓名/编号表头、指标区域等增强副本；识别后按原图坐标去重合并，归档时保存校对后的 OCR 原文、总结、全部结构化指标、数字和原始照片
- OCR 采用快速路径：先跑整图和表头，姓名/编号或指标不足时才补跑重点区域；本地 Service Worker 会缓存已使用的 OCR 运行时和 PP-OCRv6 small 模型，重复识别无需重新下载
- 已归档资料详情中可直接查看结构化指标和复制归档总结；导出的 JSON 也包含这些字段，可作为原始备份

## 本地运行

建议使用本地 HTTP 服务，以获得摄像头权限和 Service Worker 能力：

```powershell
python -m http.server 8080
```

然后打开 `http://localhost:8080`。

如果页面仍显示旧版提示，先关闭旧标签页，再重新打开地址；电脑端可使用 `Ctrl+F5` 强制刷新，以加载最新的本地脚本和识别规则。

当前 PP-OCRv6 small 检测/识别模型、PaddleOCR.js SDK、OpenCV.js、js-yaml、Clipper、SheetJS 和 ONNX Runtime Web WASM 文件均随项目放在本地 `models/` 与 `vendor/`，核心 OCR 和 Excel 导出不依赖 CDN，也不会访问百度 BCE 模型地址。PaddleOCR 官方浏览器 SDK 返回识别文字、文字框和置信度。

## 重要限制

这是功能原型，不是经过医疗合规认证的电子病历系统。自动类型识别、个人信息提取和归纳采用本地关键词与规则，不代表诊断意见；“指标明细表”中的每项指标默认标记为“待人工核对”，不能直接作为最终科研数据库。导出包为便于本机链接而保留姓名和病案/就诊号，对外共享或进入科研分析前必须按研究方案完成去标识化、字段定义、人工复核和审计。浏览器清理站点数据、卸载浏览器或更换设备可能导致本机档案丢失。正式使用前应增加设备级加密、访问口令/生物认证、可靠的本地备份与审计机制。
