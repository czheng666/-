# 本机高精度 OCR

这是当前临床采集网页的本机增强识别层。它只监听 `127.0.0.1`，不开放给医院内网，也不把图片上传到外部服务。

## 使用

1. 首次准备环境：双击 `准备高精度OCR环境.cmd`。首次需要联网安装依赖并下载模型。
2. 日常使用：双击 `启动高精度本机版.cmd`，浏览器会自动打开本地网页。
3. 在网页中仍然使用手机拍照、相册导入和原有归档流程；选择“本机高精度 OCR”后识别。

本机服务使用 RapidOCR 的 ONNX Runtime 后端和 PP-OCRv5 server 检测/识别模型，并对手机拍屏图片生成多种增强版本后择优。官方模型列表说明 RapidOCR 支持 PP-OCRv5 中文 server 模型和 ONNX Runtime 后端。

## 约束

- 该服务不等于医院信息系统，不读取医院数据库。
- 模型首次准备后可以断网运行。
- 识别结果仍必须人工复核，不能把 OCR 结果直接当成医疗诊断或最终研究标签。
- 目前先返回完整 OCR 文本和文字框；现有网页继续负责姓名/住院号提取、阑尾炎字段归档和 Excel 导出。
